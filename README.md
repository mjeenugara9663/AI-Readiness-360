# AI Readiness 360

A free, browser-based AI readiness self-assessment by **Tech Talks with Manju**.

## What it does
- 25 questions: five profile questions and 20 scored scenarios
- AI readiness score out of 100 and four category scores
- Personalised learning recommendations and a 30-day roadmap
- Downloadable Certificate of Participation (self-assessment only)
- Print / Save PDF report with clickable learning links

## Test locally
Download `index.html` and open it with a modern browser (Chrome or Edge). No installation, account, API key, or server needed.

## Scoring review
See [Scoring Review](docs/SCORING_REVIEW.md) for the question-by-question scoring and level boundaries.

## Privacy and status
Assessment responses are processed in the browser; no server, backend, account, or analytics tracking is included in this version. The tool is an informal educational self-assessment, **not a professional certification or validated benchmark**.
